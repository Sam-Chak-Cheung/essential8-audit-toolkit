# Essential Eight Checklist

Use this checklist to capture assessment status, evidence, gaps, and remediation actions.

| Control | Assessment Questions | Status | Evidence | Gaps / Actions |
| --- | --- | --- | --- | --- |
| Application control | Are approved applications defined, enforced, monitored, and reviewed? | Not assessed |  |  |
| Patch applications | Are application patches assessed, prioritised, deployed, and reported? | Not assessed |  |  |
| Microsoft Office macro settings | Are macros restricted, trusted locations controlled, and risky macro behaviour blocked? | Not assessed |  |  |
| User application hardening | Are browsers, PDF readers, Java, web ads, and risky content settings hardened? | Not assessed |  |  |
| Restrict administrative privileges | Are privileged accounts identified, limited, monitored, and regularly reviewed? | Not assessed |  |  |
| Patch operating systems | Are operating system patches assessed, prioritised, deployed, and reported? | Not assessed |  |  |
| Multi-factor authentication | Is MFA enforced for privileged access, remote access, cloud services, and important systems? | Not assessed |  |  |
| Regular backups | Are backups protected, monitored, tested, and recoverable within business requirements? | Not assessed |  |  |

## Assessment Notes

- Record control owner, scope, date assessed, assessor, evidence source, maturity target, and residual risk.
- Validate evidence against actual implementation, not only policy intent.
- Track remediation actions with due dates and accountable owners.
