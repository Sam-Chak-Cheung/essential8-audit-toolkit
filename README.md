# Essential8 Audit Toolkit

## Purpose

This starter toolkit provides practical templates for assessing Australian Essential Eight controls and collecting supporting evidence.

## What is Essential Eight

The Essential Eight is a set of mitigation strategies from the Australian Cyber Security Centre designed to help organisations improve resilience against common cyber threats.

## Maturity Model Overview

The toolkit is structured around maturity levels, control intent, implementation status, evidence quality, and remediation actions.

## Assessment Areas

- Application control
- Patch applications
- Configure Microsoft Office macro settings
- User application hardening
- Restrict administrative privileges
- Patch operating systems
- Multi-factor authentication
- Regular backups

## Checklist

Use [checklists/essential8-checklist.md](checklists/essential8-checklist.md) to record control status, ownership, evidence, gaps, and next actions.

## Evidence Examples

Use [examples/evidence-register-template.csv](examples/evidence-register-template.csv) as a starting point for tracking screenshots, policy references, configuration exports, ticket records, and validation notes.

Scripts are placeholders or defensive read-only helpers only. See [scripts/README.md](scripts/README.md).

## Disclaimer

This project is for educational and defensive security purposes only. It is an assessment template and does not replace formal legal, regulatory, audit, or risk advice.
