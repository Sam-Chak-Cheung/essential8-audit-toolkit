# Sample Essential Eight Assessment Summary

## Scope

- Organisation: Example Australian business unit
- Systems: Managed Windows endpoints, Microsoft 365, identity platform, backup platform
- Assessment type: Starter maturity review
- Date: 2026-06-02

## Executive Summary

This sample summary shows how an Essential Eight review can be presented to technology and risk stakeholders. It is intentionally generic and should be tailored to the actual organisation, scope, evidence, and target maturity level.

## Summary Ratings

| Control | Sample Status | Notes |
| --- | --- | --- |
| Application control | Partially implemented | Policy intent exists, but enforcement coverage requires validation. |
| Patch applications | Partially implemented | Patch reporting exists for core applications; exception tracking should be improved. |
| Microsoft Office macro settings | Implemented with gaps | Macro restrictions are configured, but trusted locations need review. |
| User application hardening | Partially implemented | Browser hardening is managed; PDF reader settings require evidence. |
| Restrict administrative privileges | Partially implemented | Privileged groups are known, but periodic access review evidence is incomplete. |
| Patch operating systems | Implemented with gaps | Server and endpoint patch reports are available; remediation SLA evidence should be retained. |
| Multi-factor authentication | Implemented with gaps | MFA is enabled for most users; legacy authentication and exceptions need confirmation. |
| Regular backups | Partially implemented | Backup jobs are monitored; restore test evidence should be formalised. |

## Priority Actions

1. Confirm target maturity level with business and risk owners.
2. Build a single evidence register with named owners.
3. Validate MFA coverage and legacy authentication status.
4. Formalise privileged access review evidence.
5. Record backup restore test results and recovery objectives.
