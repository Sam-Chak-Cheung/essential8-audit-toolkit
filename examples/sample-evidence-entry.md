# Sample Evidence Entry

## Control

Multi-factor authentication

## Evidence Source

Identity provider MFA registration and Conditional Access policy export.

## Sample Evidence Notes

- MFA registration report reviewed for all active users.
- Conditional Access policies reviewed for privileged roles, remote access, and cloud application access.
- Break-glass accounts identified and exception handling noted.
- Legacy authentication status requires additional validation.

## Suggested Evidence Quality

Strong evidence includes dated exports, screenshots of policy configuration, access review records, exception approvals, and monitoring logs.
