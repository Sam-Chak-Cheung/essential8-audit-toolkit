# Essential Eight Maturity Model Summary

The Essential Eight maturity model helps organisations understand how effectively controls are implemented against increasing levels of adversary tradecraft.

## Practical Assessment Approach

1. Define scope, including business units, platforms, cloud services, and identity systems.
2. Identify the target maturity level agreed by risk owners.
3. Collect evidence from configuration, monitoring, vulnerability management, backup, identity, and change records.
4. Compare implementation against the target maturity level.
5. Document gaps, compensating controls, risk acceptance, and remediation priorities.

## Evidence Quality

Strong evidence usually includes system-generated configuration, audit logs, policy settings, coverage reports, test results, and dated review records.

Weak evidence usually includes verbal confirmation, outdated screenshots, draft policies, or undocumented exceptions.
